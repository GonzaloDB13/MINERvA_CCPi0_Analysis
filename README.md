# MINERvA CCπ0 Analysis

Scientific analysis software developed for my research with the
MINERvA neutrino experiment at Fermilab.

This repository contains C++ and Python code used in my analysis of
charged-current neutral-pion (CCπ0) interactions.

## Technical Highlights

This project demonstrates experience with:

- Scientific software development in C++
- Python-based data analysis and automation
- ROOT data analysis
- Object-oriented programming
- Processing large particle-physics datasets
- Statistical analysis and systematic uncertainties
- Data visualization
- Monte Carlo simulation analysis

## Repository Structure

### `CCPi0_Macros/`

My primary analysis software, including event processing, histogramming,
statistical analysis, and visualization tools.

## Software Environment

The analysis was originally developed using the MINERvA software
ecosystem, including:

- MAT
- MAT-MINERvA
- UnfoldUtils
- ROOT

The code reflects the historical MINERvA software environment used
during the analysis and is preserved here as a research software
portfolio.
